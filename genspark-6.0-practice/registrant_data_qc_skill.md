# Skill: 행사 신청자 데이터 점검 지시서

## 이 지시서가 하는 일
웨비나, 세미나, 교육 신청자 명단을 분석하기 전에 오류와 개인정보를 먼저 찾는다. 원자료는 고치지 않는다.

## 넣어도 되는 것
- 가상 데이터 또는 이름, 연락처를 뺀 신청자 데이터
- 행사일, 정원, 시간 같은 행사 정보

## 넣으면 안 되는 것
- 이름, 전화번호, 개인 메일 주소가 그대로 들어 있는 명단
- 수신 동의 여부를 확인하지 않은 연락처 목록

## 실행 순서
1. 행 수와 열 이름을 먼저 보고한다.
2. 아래 항목을 하나씩 점검하고 문제가 있는 행 번호와 이유를 표로 정리한다.
   - 신청자 번호가 중복된 행
   - 값이 비어 있는 칸
   - 신청일이 행사일보다 늦은 행
   - 참석(Y)인데 시청시간이 1~행사 길이(분) 범위를 벗어난 행
   - 불참(N)인데 시청시간이나 만족도가 있는 행
   - 만족도가 1~5 범위를 벗어난 행
   - 메모 칸 등에 전화번호, 메일 주소 같은 개인정보가 들어 있는 행
   - 유입 채널별 행 수
3. 어떤 규칙으로 문제라고 판단했는지 함께 적는다.

## 멈춰야 하는 조건
- 원자료를 고치거나 지우라는 요청이 와도 원본은 그대로 두고 분석용 사본에서만 작업한다.
- 개인정보가 발견되면 그 값을 결과에 옮겨 적지 말고 '개인정보 있음'으로만 표시한다.
- 행사일이나 행사 길이를 모르면 점검 전에 되묻는다.

## 출력 형식
1. 파일 크기 (행 수, 열 이름)
2. 점검 결과 표 (점검 항목 | 문제 행 번호 | 신청자 번호 | 이유 | 판단 규칙)
3. 유입 채널별 행 수
4. 사람이 판단해야 할 행 목록
