## Aside 준비 (보류: 원격 호스트가 Pro 플랜 필요)
```bash
curl -fsSL https://releases.aside.com/install.sh -o /tmp/aside_install.sh && bash /tmp/aside_install.sh
mkdir -p ~/.aside/cli && printf '%s' "$ASIDE_CLI_AUTH_JSON" > ~/.aside/cli/auth.json && chmod 600 ~/.aside/cli/auth.json
export PATH=$HOME/.local/bin:$PATH
aside account status && aside host list
```
- 젠스파크에 로그인된 Aside 브라우저가 있는 호스트(사용자 Mac 원격 제어 등)를 `aside host use <host>`로 지정한다.
- 캡처는 `aside repl`로 페이지를 열고 screenshot을 찍어 로컬로 받은 뒤, 노션 create-file-upload로 올린다.
- 실습은 표준 모드만. Ultra, 영상 생성 금지. 메일은 초안까지만, 발송 금지.
